# ころいろ 〜ふーさんの のこり色にご用心〜

サイコロの目と同じ数字のカードを 4×4 の場から集める、2〜4人用のブラウザ・カードゲームです。ラウンドの終わりに **場に残った色** のカードは手元から全部ふっとびます。空いた席には ふーさん🐻 が入ります。
ひとり1台のスマホ（iPhone Safari / Android）や PC で遊べます。P2P（PeerJS）でホストの端末が進行役になり、サーバーは使いません。

> 市販のカードゲーム「JINX」（Piatnik／作：Klaus Altenburger／日本語版：ジーピー）の **ルールの仕組み** を参考にした、非公式のファンメイド作品です。
> 名前・テーマ・見た目・UI文はすべてオリジナルで、製品の名前・アート・ロゴ・ルールブックの文章は使っていません。ルールの調査と解釈は [RULES_NOTES.md](RULES_NOTES.md) にまとめています。

## 遊び方（かんたん）
1. 全3ラウンド。毎ラウンド、16枚のカードを 4×4 に並べる（補充なし）。
2. 手番では 🎲 を振る（1回だけ振り直せる）。出目と同じ数字のカードを1枚取る（色は関係なし）。
3. 出目に合うカードが場になければラウンド終了。**場に残った色のカードは全員ぜんぶ捨てる**。終わらせた人は、さらに手元の一番大きい数字を1枚捨てる。
4. 1・2ラウンドのあと、カード1枚を「おたすけ札」1枚と交換できる（＋1／−1／もう1回ダイス／いろまとめ／ちいさめ指名 1·2·3／おおきめ指名 4·5·6）。
5. 3ラウンド後、手元の数字の合計がいちばん大きい人の勝ち。

## 特徴
- 部屋コード／招待URL／QRで参加（2〜4人）。「🐻 ふーさんと ひとりで遊ぶ」は通信なし。
- ふーさん🐻：弱い／普通／強い／アストラウルトラ😎（覚醒演出つき）。どのレベルも見えている情報だけで考えます（山札の順番やサイコロの先の目は見ません）。
- スマホ縦画面に合わせたレイアウト（375px幅でもスクロールなし）。
- 🏠 ひろばへ（`?from=portal` またはホーム画面アプリのとき表示、プレイ中は ⋯ メニューから）。

## ファイル
- `index.html` … 画面とスタイル
- `core.js` … 共通の定数（色・おたすけ札の名前・タイミング）・小道具・汎用UI・あそびかた
- `audio.js` / `bgm.js` … 効果音・BGM（Web Audio で合成）
- `fx.js` … ふーさん覚醒・カットイン・紙ふぶき
- `host.js` … ホスト側のゲーム進行（authoritative）
- `net.js` … PeerJS の通信（ホスト受付・参加者）
- `ui.js` … 画面の描画
- `app.js` … ボタン操作・タイトル・全体の流れ（最後に読み込む）
- `logic.js` … ルールエンジンとふーさんAI（DOMに依存しない、Node でも動く）
- `config.js` … STUN/TURN の設定（`SR_CONFIG.iceServers`）
- `vendor/` … peerjs, qrcode
- `RULES_NOTES.md` … ルール調査メモ（情報源・あいまいな点の決め方）
